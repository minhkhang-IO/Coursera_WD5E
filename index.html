Four Implemented "Extras"

Advanced CSS3 capabilities integrated into this stylesheet for accessibility and user preference adaptation.

1. Auto Dark Mode

Uses @media (prefers-color-scheme: dark) paired with CSS Custom Properties to adapt colors automatically.

2. Fluid Typography

Implements mathematical clamp() functions so headings scale smoothly without abrupt breakpoint jumps.

3. Reduced Motion Support

Respects @media (prefers-reduced-motion: reduce) by disabling hover transitions for vestibular comfort.

4. Print-Optimized Layout

Includes a dedicated @media print rule that strips navigation bars and formats the page cleanly for PDF export.
